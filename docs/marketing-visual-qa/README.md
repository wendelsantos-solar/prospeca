# Marketing Visual QA

Screenshots de validação visual da landing page após V2.

## Resoluções a capturar

| Viewport   | Dispositivo      |
| ---------- | ---------------- |
| 1440 × 900 | Desktop amplo    |
| 1366 × 768 | Notebook comum   |
| 1280 × 800 | Notebook menor   |
| 1024 × 768 | Tablet landscape |
| 768 × 1024 | Tablet portrait  |
| 390 × 844  | iPhone 14        |
| 360 × 800  | Android comum    |

## Checklist de verificação

### Hero & Header

- [ ] Header visível, não sobrepõe conteúdo
- [ ] Headline integralmente visível acima da dobra (1366×768)
- [ ] CTA visível acima da dobra
- [ ] Mockup parcialmente visível acima da dobra
- [ ] Menu mobile funcional

### Layout & Espaçamento

- [ ] Containers alinhados
- [ ] Ritmo entre seções consistente
- [ ] Sem áreas vazias excessivas
- [ ] Sem overflow horizontal

### Mockups & Demonstrações

- [ ] Mapa com marcadores visíveis
- [ ] Pipeline com cards de lead
- [ ] Score com critérios legíveis
- [ ] Mensagem com preview visível

### Preços

- [ ] Cards alinhados
- [ ] Toggle mensal/anual funcional
- [ ] Plano destacado visível

### FAQ

- [ ] Itens expandem/colapsam
- [ ] Animação suave
- [ ] Funcional por teclado

### Footer

- [ ] Links funcionais
- [ ] Layout responsivo

### Mobile

- [ ] Headline sem quebra ruim
- [ ] CTA com largura adequada
- [ ] Cards empilhados
- [ ] FAQ acessível
- [ ] Sem overflow horizontal
